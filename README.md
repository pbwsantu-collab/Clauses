# 📘 Clause Mastery – Interactive Ebook (Class X)

A complete, interactive HTML ebook designed for **Class X students** (West Bengal Board, CBSE, ICSE, and other state boards) to master **clauses** in Bengali. This ebook contains **50 joining questions for each clause type** (Noun, Adjective, Adverb) with clickable answers and detailed explanations in Bengali.

---

## 🔍 What’s Inside

- **Total 150+ practice questions** – 50 for each clause type.
- **Three major sections:**
  - Noun Clause (বিশেষ্য ধারা)
  - Adjective Clause (বিশেষণ ধারা)
  - Adverb Clause (ক্রিয়া-বিশেষণ ধারা)
- **Interactive answer toggle** – Click to reveal the correct joined sentence and a clear Bengali explanation.
- **Clean, responsive design** – Works on desktop, tablet, and mobile.
- **Self‑paced learning** – Perfect for revision, homework, or exam preparation.

---

## 📖 How to Use

1. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
2. Scroll through the three sections.
3. Read each question (two short sentences to join).
4. Think of the correct way to join them using the appropriate clause.
5. Click the **“উত্তর দেখুন”** button to check your answer and read the explanation.
6. Click **“উত্তর লুকান”** to hide the answer and try again.

> 💡 All explanations are in **Bengali** to ensure clear understanding for Class X students.
